# Konush — конкретные изменения за 26 сентября 2026

Изменения внесены в исходный код `konush-mobile-repo`. Сборка нового APK остановлена по просьбе пользователя. Существующий APK остался от 15 сентября. Ниже перечислены изменения текущей работы, а не весь накопленный Git diff проекта.

## Исправлено: что было и что стало

| Место | Было | Что изменено |
|---|---|---|
| Подключение к серверу | Приложение по умолчанию использовало старые HTTP-адреса | Установлены новые адреса REST, WebSocket и медиа; используются HTTPS/WSS |
| Мои объявления | Своя карточка загружалась через публичный API; на новом сервере непубличное объявление даёт 404 | Добавлен запрос владельца и отдельный маршрут открытия своего объявления |
| Статусы объявлений | Значение `removed` не обрабатывалось отдельно | Оно отображается как архивное; в своей карточке показан статус проверки, публикации или отклонения |
| Действия на своей карточке | Использовались общие действия карточки продавца | В режиме владельца скрыты действия звонка, переписки и добавления собственного объекта в избранное |
| Недоступное избранное | Карточка открывала публичную страницу и могла приводить к 404; гостевой сохранённый ID удалялся при 404 | Обрабатывается `is_public`, карточка отмечается недоступной, переход отключён; гостевой ID сохраняется и может быть удалён самим пользователем |
| Каталог ЖК | Запросы шли на `/complexes`; при ошибке оставались встроенные примеры | Используется `/residential-complexes`; добавлены настоящая загрузка, пустое состояние, ошибка и повторная попытка |
| Новостройки | Использовалась отдельная демонстрационная выдача | Раздел направлен в реальный каталог ЖК |
| Повторная отправка фото после обновления сессии | Повторное использование уже отправленного multipart-тела могло сорвать запрос | Перед повтором после 401 создаётся новая копия тела с фотографией |

## Добавлено

### Подача объявления

Раньше экран содержал выбор сделки/типа недвижимости, сообщение о будущей функции и отключённую кнопку. Теперь добавлены:

- Выбор продажи, аренды или посуточной аренды и типа недвижимости.
- Заголовок, описание, цена в сомах, возможность торга, площадь, комнаты, этаж и этажность.
- Выбор города, адрес и выбор расположения на карте.
- Выбор фотографий из галереи, предварительный просмотр и удаление ещё не загруженного фото.
- Проверка обязательных полей, чисел, длины текста, формата и размера фотографий.
- Создание объявления через API и последовательная загрузка фотографий.
- Отображение результата «На проверке» и переход к своей карточке.
- Блокировка двойного нажатия во время отправки.
- Сохранение ID созданного объявления и уже загруженных фотографий внутри открытой формы: повторная попытка после однозначной ошибки продолжает загрузку, не создавая второе объявление.
- При неопределённом результате сетевого запроса — предложение проверить свои объявления перед повторной отправкой.
- Подтверждение выхода из заполненной формы и блокировка закрытия во время отправки.
- Проверка входа и подтверждения телефонного номера перед подачей.

Состояние незавершённой формы не сохраняется как постоянный черновик между перезапусками приложения.

### Реальные данные ЖК

- Поиск по названию комплекса или застройщика.
- Фильтр сданных комплексов и загрузка следующих страниц.
- Карточки с фотографиями, застройщиком, адресом, сроком сдачи, готовностью и ценой при наличии этих данных.
- Страница комплекса с описанием и галереей.
- Список доступных квартир, офисов и паркингов: цена, площадь, комнаты, этаж, корпус, планировка и фото при наличии.

Публичный список ЖК на проверенном сервере сейчас пуст. Заполненные ответы проверены локальными тестовыми данными.

### Языки и платформы

- Добавлены 64 пары русских и кыргызских сообщений; обновлены ARB-каталоги и сгенерированная локализация.
- Подключён плагин выбора фотографий и обновлены его зависимости/регистрации на платформах.
- Для iOS добавлено описание доступа к фотогалерее.
- Убраны прежние общие исключения для незашифрованного HTTP в Android и iOS.

## Что реально проверено

- Полный прогон: **149 тестов прошли**, включая 13 новых проверок интеграции и формы.
- На staging проверены вход, профиль, избранное, список диалогов, обновление токенов, выход, публичные объявления и чтение фотографии.
- WebSocket открылся и оставался подключённым после кадра авторизации. Отправка и доставка сообщений между пользователями не проверялись.
- На staging создан один технический объект: статус `pending`, фотография загружена, владелец открыл карточку, публичный запрос вернул 404.
- Проверочный объект удалён; удаление подтверждено повторным запросом. Проверочная сессия завершена.

## Текущее состояние

- Изменения исходного кода приложения находятся в локальной рабочей копии; их коммит и публикация не выполнялись. Этот отчёт опубликован отдельно.
- Сборка APK остановлена. Новый установочный файл не получен.
- Последние небольшие правки после полного прогона ещё требуют повторной проверки. Последний сохранённый статический анализ содержал замечания; часть затем исправлена, итоговый чистый прогон пока не подтверждён.
- Нативный выбор фотографий и весь пользовательский сценарий на физическом телефоне пока не проверялись.
- Ипотека, рассрочки и обратные звонки найдены в новом API, но в этой работе в мобильный интерфейс не добавлялись.

Материалы проверки сохранены локально: сравнение API (`README.md`), журнал тестов (`all-tests.log`), результаты проверки подачи на сервере (`submission-live-checks.json`).
